IROS 2026 Tutorial

Learning-to-Optimize for Control in Robotics

A hands-on tutorial on learning-to-optimize methods for real-time MPC, sampling-based control, and adaptive robotic control.

View schedule Hands-on materials

Overview

This tutorial introduces learning-to-optimize (L2O) as a practical framework for accelerating and improving optimization-based control in robotic applications.

The tutorial focuses on real-time model predictive control, efficient sampling-based control, and learning-to-adapt methods for controllers operating under changing dynamics and uncertain environments. The hands-on examples will use the Ctrl-L2O toolbox to demonstrate these ideas across robotic systems such as autonomous vehicles, quadrupedal robots, and bipedal robots, with interfaces compatible with platforms such as MuJoCo.

Format

3-hour tutorial

Two one-hour sessions, each combining lecture material and coding exercises, separated by a 30-minute break.

Software

Ctrl-L2O

Learning-to-optimize tools for robotic control, including examples for MPC, MPPI, and adaptive parameter tuning.

Audience

Robotics, control, and ML

Designed for attendees interested in optimization-based control, differentiable optimization, and deployable robotic learning.

Tutorial Contents

Part I: Introduction and Foundations

  • Opening remarks and tutorial goals.
  • Why optimization is central to modern robotic control.
  • Why real-time control and adaptation create computational bottlenecks.
  • Parametric optimization as a unifying view for MPC, MPPI, and L2O.
  • Introduction to the Ctrl-L2O software toolbox.

Preliminaries on MPC and MPPI Control

  • Model predictive control and common MPC solver toolboxes.
  • Sampling-based MPC and model predictive path integral control.
  • Coding tutorial 1: MPC with numerical solvers and sampling-based methods.

L2O Methodologies for Parametric Optimization

  • Supervised and self-supervised learning for optimization.
  • Learning parametric solution maps and warm starts.
  • Algorithm unrolling and differentiable optimization layers.
  • Fixed-point and KKT-based differentiation.
  • Feasibility restoration and constraint handling.
  • Coding tutorial 2: Synthetic L2O examples for parametric optimization.

Part II: Applications in Control and Robotics

  • L2O for real-time MPC and warm-started numerical optimization.
  • Learning components that simplify mixed-integer or structured control problems.
  • L2O for MPPI and learned sampling distributions.
  • Learning terminal costs and constraints through sampling.
  • Learning-to-adapt nonlinear MPC parameters with Bayesian optimization.
  • Automatic tuning of linear MPC to approximate nonlinear MPC behavior.
  • Coding tutorial 3: Robotic demonstrations with Ctrl-L2O.
